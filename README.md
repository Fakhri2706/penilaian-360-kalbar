# Poster Penilaian Umpan Balik 360° — Pemprov Kalimantan Barat

Paket ini siap di-upload ke GitHub Pages.

## Isi
- `index.html` — halaman poster interaktif.
- `README.md` — panduan singkat.

## Cara publikasi
1. Buat repository baru di GitHub.
2. Upload `index.html` dan `README.md` ke branch `main`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch **main** dan folder **/ (root)**.
6. Klik **Save**.
7. Setelah deployment selesai, GitHub akan memberikan URL publik.

File poster menggunakan aset yang tertanam di HTML, sehingga tidak membutuhkan folder aset tambahan.
